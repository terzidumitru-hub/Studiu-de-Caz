// 01 - FUNDAMENTE

Ce este GIT?

Git este un sistem distribuit de control al versiunilor care înregistrează istoricul modificărilor. Permite colaborarea în paralel fără suprascrierea codului sursă.

$ git log --oneline

Ce este GitHub?

GitHub este o platformă cloud de găzduire și colaborare. Oferă instrumente precum Pull Requests, Code Review și integrare continuă (CI/CD).
